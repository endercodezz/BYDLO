# Пользовательские темы

В основном переключателе доступны «Светлая», «Чёрная» и «Системная».
Встроенная «Фиолетовая» находится в группе «Пользовательские темы»
в настройках и на экране первого запуска. Она доступна без импорта файла.
На первом запуске выбрана системная тема. При обновлении сохраняется прежний
выбор, включая фиолетовую и бывшую OLED (теперь «Чёрная» / Black): значения
`Purple`, `Oled` и остальные идентификаторы в настройках не меняются.
Дополнительные темы — это JSON-файлы только с цветами: их можно импортировать
из файла, экспортировать текущую палитру как шаблон и ставить из галереи
в репозитории. Загружать чужой AXAML нельзя: в XAML можно создать любой объект,
а это риск для VPN-клиента; к тому же runtime-XAML плохо совместим с trimming/AOT.

## Формат

```json
{
  "id": "ocean",
  "name": "Ocean",
  "author": "someone",
  "version": 1,
  "base": "dark",
  "colors": {
    "Bg": "#0F1A24",
    "Surface": "#15222E",
    "Primary": "#2E8FB8",
    "Accent": "#5EC8E5",
    "Text": "#E8F1F5"
  }
}
```

- `id`: 1–32 символа, строчные латинские буквы, цифры и дефисы. Имя файла —
  `themes/<id>.json`, установка — в `<данные>/themes/<id>.json`.
- `version`: всегда `1`.
- `base`: `dark` (базовая палитра Purple, тёмный вариант контролов) или
  `light` (базовая палитра Light, светлый вариант).
- `colors`: от 1 до 64 записей. Недостающие ключи берутся из базовой темы,
  неизвестные игнорируются (счётчик показан после импорта).
- Цвета: `#RRGGBB`, `#AARRGGBB` или `Transparent`. Конец строки строгий:
  пробелы и переводы строки внутри значения запрещены (`#112233\n` отвергается,
  потому что такое значение роняло бы применение темы). Размер файла — до 64 КиБ.
- Ключи `Expander*` пишутся как в палитре, без суффикса (`ExpanderHeaderBackground`,
  а не `...Brush`); экспорт текущей темы даёт именно такие имена, импорт их понимает.
- Контраст считается с учётом прозрачности: полупрозрачный текст композитится
  поверх фона, полностью прозрачный даёт предупреждение всегда.
- Сломанный файл не роняет приложение: тема откатывается на базовую.
- Контраст: если `Text` плохо читается на `Bg` / `Surface` (ниже WCAG AA 4.5:1),
  приложение показывает предупреждение, но тему применяет.

Короткие ключи (`Bg`, `Primary`) отображаются на ресурсы палитры (`BgBrush`,
`PrimaryBrush`); `AccentColor` и `PrimaryColor` пишутся как есть.

## Токены

| Ключ | Назначение |
|---|---|
| `Bg`, `Backdrop` | Фон окна |
| `Sidebar`, `NavActive` | Боковая панель и активный пункт |
| `Surface`, `Surface2`, `SurfaceHover` | Карточки и ховер |
| `Line`, `Edge` | Разделители и рамки |
| `Primary`, `PrimaryHover`, `PrimaryPressed`, `ButtonEdge`, `OnPrimary` | Акцентные кнопки |
| `Accent`, `AccentSoft` | Ссылки, свечение, мелкие акценты |
| `Text`, `TextMuted`, `TextFaint` | Текст трёх уровней |
| `Success` / `SuccessSoft`, `Warning` / `WarningSoft`, `Danger` / `DangerSoft` | Статусы |
| `Scrim` | Затемнение модальных окон |
| `ExpanderHeaderBackground`, `ExpanderHeaderBackgroundPointerOver`, `ExpanderHeaderBackgroundPressed`, `ExpanderContentBackground`, `ExpanderContentBorderBrush`, `ExpanderHeaderBorderBrush`, `ExpanderHeaderBorderBrushPointerOver`, `ExpanderHeaderBorderBrushPressed` | Раскрывающиеся панели |
| `AccentColor`, `PrimaryColor` | Системные акценты Fluent |

Полный список ключей — в `Purple.axaml` / `Light.axaml` / `Oled.axaml`;
набор во всех трёх палитрах одинаковый.

## Где в интерфейсе

Настройки → Внешний вид → «Пользовательские темы»: установленные темы
(применить, удалить), «Импорт из файла», «Экспорт текущей» (сохраняет
текущую палитру как шаблон), «Галерея тем».

Применение, удаление и переустановка мгновенные. Выбор переживает перезапуск
(хранятся `Theme` и `CustomThemeId` в настройках). Удаление активной темы
возвращает Purple. Резервная копия (`docs/BACKUP.md`) файлы тем не включает:
после восстановления применяется файл из текущего каталога данных, при его
отсутствии — Purple.

## Галерея из репозитория

- `themes/<id>.json`, общий `themes/index.json` вида
  `[{"id": "...", "name": "...", "author": "...", "url": "..."}]`.
- Приложение скачивает индекс по raw-ссылке **только по нажатию кнопки**,
  показывает список, выбранную тему сохраняет локально. Лимит — 64 КиБ
  на файл, в индексе — до 100 записей, ссылки — только `https://`.
- Новую тему присылают через pull request: `themes/<id>.json` плюс запись
  в `themes/index.json`. Держите палитру читаемой (контраст 4.5:1),
  проверяйте образец локально импортом из файла.

## Безопасная проверка

```powershell
. ./scripts/env.ps1
./scripts/check.ps1
```

Модульные тесты (`tests/Bydlo.Tests/CustomThemeTests.cs`) проверяют парсер,
валидацию, контраст и файловое хранилище без сети и окна.

## Безопасная проверка интерфейса

В новом каталоге результатов можно проверить первый запуск, загрузку старых настроек,
выбор фиолетовой в пользовательских темах и переключение на чёрную:

```powershell
. ./scripts/env.ps1
dotnet run --project tools/Bydlo.Screenshots -c Release -- .tmp/themes-134 ru --verify-themes --mock
```

Для английского интерфейса используйте `en` и отдельный новый каталог результатов.
Проверка работает в headless и Mock Mode, реальные движки не запускаются.
